# Atomic 120 Hz

Aplicativo Android nativo em Kotlin para detectar modos de tela e solicitar frequências compatíveis, sem root como requisito.

**Importante:** Hz da tela não é FPS renderizado pelo jogo. O Android/fabricante pode ignorar a solicitação e o app nunca deve afirmar que ativou um modo sem confirmação.

Abra no Android Studio, sincronize o Gradle e compile o módulo `app`.
